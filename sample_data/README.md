# Sample Data

이 폴더는 실제 계좌 데이터를 넣지 않고도 CSV 형식과 보조 캐시 파일의 모양을 확인하기 위한 샘플입니다.

- `snapshot_sample.csv`: 날짜별 계좌 스냅샷 샘플입니다. 실제 사용 시에는 `data/YYYY-MM-DD.csv` 또는 `data/snapshots/YYYY-MM-DD.csv`에 같은 열 구조로 둡니다.
- `portfolio_labels.sample.csv`: 사용자 정의 자산 라벨 샘플입니다. 실제 사용 시에는 `data/portfolio_labels.csv`로 복사해 자신의 분류 체계를 적습니다.
- `security_map.sample.csv`: 증권사 종목명과 외부 심볼 매핑 캐시의 예시입니다.

샘플 값은 모두 가짜 데이터이며 매매 추천이나 실제 종목 판단을 의미하지 않습니다.
