# Portfolio Blackbox

개인 투자 계좌의 일별 스냅샷을 수집하고, 시간에 따른 포트폴리오 변화와 성과 원인을 분석하는 Flask 기반 대시보드입니다.

이 프로젝트는 **매매 추천, 종목 추천, 자동매매, 진입/청산 신호 생성**을 목표로 하지 않습니다. 핵심 줄기는 데이터 분석입니다. 매일의 계좌 기록을 신뢰할 수 있게 쌓고, 그 기록을 바탕으로 다음 질문에 답하는 개인 투자 복기 도구를 만드는 것이 목표입니다.

> 나는 어떤 자산에 노출되어 있고, 시간이 지나며 내 판단은 실제로 어떤 결과를 냈는가?

## 방향성

Portfolio Blackbox는 계좌를 하나의 분석 대상 데이터셋으로 봅니다.

- 일별 보유 종목, 평가금액, 손익, 현금성 자산을 안정적으로 기록합니다.
- 계좌 총액 변화가 어떤 종목, 자산군, 매수/매도 이벤트에서 비롯됐는지 설명합니다.
- 포트폴리오가 특정 종목, 섹터, 통화, 자산군에 얼마나 노출되어 있는지 보여줍니다.
- 예측 기능은 매수/매도 판단이 아니라 실제 계좌 흐름과 모델 오차를 복기하는 보조 데이터로만 사용합니다.
- 최종적으로는 주간/월간 투자 회고 리포트를 자동으로 만들 수 있는 구조를 지향합니다.

## 현재 기능

### 데이터 기록

- `data/YYYY-MM-DD.csv` 형태의 날짜별 계좌 스냅샷을 읽습니다.
- 과거 CSV 템플릿과 최신 CSV 템플릿을 공통 형식으로 정규화합니다.
- `data/account_value.csv`로 날짜별 총 계좌 평가금액 추이를 관리합니다.
- `data/portfolio_data.csv`로 최신 포트폴리오 정규화 파일을 생성합니다.
- `data/security_map.csv`로 증권사 종목명과 외부 가격 API 심볼의 매핑 캐시를 관리합니다.
  새 종목은 자동 추정 후 `검산 가능 / 확인 필요 / 별도 자산`으로 분류합니다.
- `data/kr_security_master.csv`는 KIS 코스피/코스닥/코넥스 종목코드 마스터 파일을 정규화한
  국내 종목 사전입니다. 데이터 품질 탭에서 필요할 때 갱신합니다.

### 계좌 분석 대시보드

- 현재 포트폴리오 테이블
- 종목별 비중 차트
- 계좌 총액과 수익률 추이
- 성과 원인 분석
- 리스크와 노출 분석
- 계좌 흐름과 예측 오차 복기
- 투자 이벤트 타임라인
- 날짜별 스냅샷 상세
- 추정 실현/미실현 손익
- 섹터 분포와 시장 보조 데이터
- USD/KRW 환율 차트

### 관심목록

관심목록은 매매 추천을 위한 공간이 아니라 리서치 메모와 참고 데이터 확인용으로 둡니다.

- 관심종목 추가/삭제
- Finnhub 기반 시세/기업 지표 조회
- KIS API 기반 해외주식 일봉 차트 조회
- 참고용 변동성 지표 확인

### 예측 실험

예측 기능은 투자 결정을 대신하지 않습니다. 실제 계좌 흐름이 평소 범위에서 벗어났는지, 모델이 어떤 구간에서 자주 틀리는지 확인하기 위한 분석 실험입니다.

- 계좌 총액 예측
- USD/KRW 환율 예측
- Linear, Holt, ARIMA 모델 지원
- 모델별 MAE/RMSE/MAPE/방향성 정확도 계산
- 예측 스냅샷 저장과 실제값 반영 구조

## 데이터 흐름

```text
data/YYYY-MM-DD.csv
        |
        v
data.csv_manager.normalize_snapshot_csv()
        |
        +--> data/account_value.csv
        +--> data/portfolio_data.csv
        |
        v
services.snapshots / analysis services
        |
        v
Flask API routes
        |
        v
templates/index.html + templates/partials + static/js/*
```

## 로드맵

## 다음 5단계

팔로업할 때마다 이 목록을 기준으로 현재 위치를 확인합니다.

1. **데이터 품질 센터**: 누락 날짜, 중복 스냅샷, 최신 총액 불일치, 급격한 총액 변동, 종목명 이상을 점검합니다.
2. **이벤트 원장 고도화**: 신규 진입, 추가 매수, 일부 매도, 전량 매도 추정 근거를 더 명확히 기록합니다.
3. **기간 필터 공통화**: 최근 1주, 1개월, 올해, 전체 같은 기간 기준을 성과/리스크/이벤트에 공통 적용합니다.
4. **성과 계산 고도화**: 단순 수익률뿐 아니라 TWR, IRR처럼 현금흐름 영향을 분리하는 성과 지표를 도입합니다.
5. **주간 회고 리포트 자동 생성**: 주요 변화, 이익/손실 원인, 리스크 변화, 다음 점검 항목을 요약합니다.

### 1. 데이터 신뢰성

- 날짜별 CSV 템플릿 차이를 흡수하는 공통 정규화 계층 유지
- `account_value.csv`와 최신 스냅샷 총액 일치 검증
- 누락 날짜, 중복 날짜, 급격한 총액 변화 감지
- 계좌번호 등 민감값의 화면 표시 기본 마스킹

### 2. 투자 이벤트 타임라인

- 신규 진입 감지
- 수량 증가/감소 감지
- 일부 매도/전량 매도 추정
- 날짜별 주요 변화 이벤트 요약
- “그날 계좌에 무슨 일이 있었는가”를 설명하는 타임라인 구축
- 이벤트 원장에는 보유 수량 전후, 추정 단가, 추정 현금흐름, 추정 실현손익, 판단 근거와 신뢰도를 함께 기록합니다.
- 매수 금액은 매입금액 증가분, 매도 금액은 직전 평가금액 기준 추정치로 표시합니다.

### 3. 기간 필터 공통화

- 대시보드 공통 기간 필터를 두고 최근 1주, 1개월, 3개월, 올해, 전체, 사용자 지정 기간을 선택합니다.
- 기본값은 최근 3개월입니다.
- 계좌 총액 차트, 성과 요약, 리스크 흐름, 손익 시계열, 이벤트 원장이 같은 기간 기준을 공유합니다.
- 전체 기간은 데이터가 많아 계산이 무거울 수 있으므로 필요할 때 선택하는 분석 모드로 둡니다.

### 4. 성과 원인 분석

- 종목별 손익 기여도
- 월별/주별 계좌 변화
- 이익 기여 상위와 손실 기여 상위
- 매도 후 성과 회고
- 보유 기간별 성과 분석

### 5. 리스크와 노출 분석

- 종목 집중도
- 섹터 노출
- 원화/달러 노출
- 현금/주식/금/ETF 비중 변화
- 시장지표와 환율의 동행성

### 6. 예측 검토

- 예측값 자체보다 실제값과 예측 오차의 흐름에 초점
- 예측 오차가 커진 날의 원인 분석
- 모델별 성능 추적
- 계좌 급락, 특정 종목 과집중, 손실 확대 구간을 회고 지표로 구분

### 7. 회고 리포트

- 주간/월간 포트폴리오 요약
- 주요 이익/손실 원인
- 매수/매도 이벤트 요약
- 리스크 변화 요약
- 다음에 확인할 항목 자동 정리

## 프로젝트 구조

```text
quant/
  app.py                         Flask 앱 진입점
  config.py                      환경변수 기반 설정
  extensions.py                  Flask 확장 객체
  data/
    csv_manager.py               CSV 스냅샷 정규화 및 파생 CSV 생성
    YYYY-MM-DD.csv               날짜별 원본 계좌 스냅샷
    account_value.csv            날짜별 총 계좌 평가금액
    portfolio_data.csv           최신 포트폴리오 정규화 파일
    security_map.csv             종목명과 외부 가격 심볼 매핑 캐시
    kr_security_master.csv       KIS 국내 종목코드 마스터 캐시
  db/
    connection.py                DB 연결
    migration.py                 CSV 데이터를 DB로 반영하는 학습/실험 영역
  routes/                        Flask API 라우트
  services/                      포트폴리오, 스냅샷, 예측, 시장 분석 로직
  static/js/                     대시보드 프론트엔드 로직
  templates/
    index.html                   앱 shell
    partials/                    화면 영역별 템플릿 조각
```

## 실행

```bash
pip install -r requirement.txt
python app.py
```

CSV를 재정규화하고 DB 마이그레이션까지 시도하며 서버를 실행하려면 다음 옵션을 사용합니다.

```bash
python app.py --refresh
```

`--refresh`는 로컬 CSV와 DB 설정을 사용합니다. 실행 전 `.env`에 API 키와 DB 접속 정보가 준비되어 있어야 합니다.

## 환경변수

`.env`에는 API 키, 계좌번호, DB 비밀번호 같은 민감 정보가 들어갑니다. 이 파일은 저장소에 커밋하지 않습니다.

주요 값은 다음과 같습니다.

- `FINNHUB_API_KEY`
- `appkey`
- `secretkey`
- `account`
- `id`
- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`
- `AUTO_REFRESH_CSV`
- `SNAPSHOT_DIR`

## 개발 메모

- 현재 프로젝트의 중심축은 `정확한 기록 -> 데이터 분석 -> 회고`입니다.
- 새 기능은 “이 기능이 내 계좌 기록을 더 잘 이해하게 해주는가?”를 기준으로 판단합니다.
- 추천 문구, 매수/매도 지시, 자동매매 흐름은 프로젝트 범위에서 제외합니다.
- 예측 모델 추가보다 데이터 품질, 이벤트 타임라인, 성과 원인 분석을 우선합니다.
- 외부 API 연동은 보조 정보로 보고, 개인 계좌 스냅샷을 가장 중요한 원천 데이터로 봅니다.
