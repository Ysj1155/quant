# Portfolio Blackbox

개인 투자 기록을 수집하고, 시간이 지나며 포트폴리오에 어떤 일이 있었는지 해석하는 Flask 기반 대시보드입니다.

이 프로젝트의 목표는 종목을 추천하거나 자동매매를 하는 것이 아닙니다. 매일의 계좌 스냅샷을 신뢰할 수 있게 쌓고, 그 기록을 바탕으로 다음 질문에 답하는 개인 투자 회고 도구를 만드는 것입니다.

> 나는 어떤 자산을 왜 들고 있고, 시간이 지나며 내 판단은 실제로 어떤 결과를 냈는가?

## 방향성

이 앱은 단순히 현재 평가금액을 보여주는 화면이 아니라, 내 투자 활동의 블랙박스가 되는 것을 목표로 합니다.

- 매일의 보유 종목, 평가금액, 손익, 현금 비중을 안정적으로 기록합니다.
- 계좌 총액 변화가 어떤 종목, 자산군, 매수/매도 이벤트에서 왔는지 설명합니다.
- 포트폴리오가 특정 종목, 섹터, 통화, 자산군에 얼마나 노출되어 있는지 보여줍니다.
- 예측 기능은 미래를 맞히기보다 추세 이탈과 이상징후를 감지하는 보조 도구로 사용합니다.
- 최종적으로는 월간/주간 투자 회고 리포트를 자동으로 만들 수 있는 구조를 지향합니다.

## 현재 기능

### 데이터 기록

- `data/YYYY-MM-DD.csv` 형태의 날짜별 계좌 스냅샷을 읽습니다.
- 오래된 CSV 템플릿과 최신 CSV 템플릿을 공통 형식으로 정규화합니다.
- `data/account_value.csv`를 생성해 날짜별 총 계좌 평가금액 추이를 관리합니다.
- `data/portfolio_data.csv`를 최신 스냅샷 기준 현재 포트폴리오 파일로 생성합니다.

### 대시보드

- 현재 포트폴리오 테이블
- 종목별 비중 차트
- 계좌 총액 및 수익률 추이
- 성과 원인 분석
- 리스크와 노출 분석
- 계좌 흐름 이상징후 감지
- 투자 이벤트 타임라인
- 날짜별 스냅샷 상세
- 추정 실현/미실현 손익
- 섹터 분포 및 시장 데이터
- USD/KRW 환율 차트

### 관심종목

- 관심종목 추가/삭제
- Finnhub 기반 시세/기업 지표 조회
- KIS API 기반 해외주식 일봉 차트 조회
- 이상징후 점수 계산

### 예측 실험

- 계좌 총액 예측
- USD/KRW 환율 예측
- Linear, Holt, ARIMA 모델 지원
- 모델별 MAE/RMSE/MAPE/방향성 정확도 계산
- 예측 스냅샷 저장 및 실제값 반영 구조

## 데이터 흐름

```text
data/YYYY-MM-DD.csv
        |
        v
data.csv_manager.normalize_snapshot_csv()
        |
        +--> data/account_value.csv
        +--> data/portfolio_data.csv
        |
        v
services.snapshots / services.portfolio
        |
        v
Flask API routes
        |
        v
templates/index.html + static/js/*
```

현재 1단계 작업의 핵심은 모든 CSV 스냅샷을 같은 방식으로 읽는 것입니다. 이 기반이 안정되어야 이후 타임라인, 성과 분석, 리스크 분석, 리포트 기능을 신뢰할 수 있습니다.

## 로드맵

### 1. 데이터 신뢰도

- 날짜별 CSV 템플릿 차이를 흡수하는 공통 정규화 계층 유지
- `account_value.csv`와 최신 스냅샷의 총액 일치 검증
- 누락 날짜, 중복 날짜, 급격한 총액 변화 탐지
- 계좌번호 등 민감값의 화면 표시 기본 마스킹

### 2. 투자 이벤트 타임라인

- 신규 매수 감지
- 수량 증가/감소 감지
- 일부 매도/전량 매도 추정
- 날짜별 주요 변동 이벤트 요약
- “그날 계좌에 무슨 일이 있었는가”를 설명하는 타임라인 구축

### 3. 성과 원인 분석

- 종목별 손익 기여도
- 월별/주별 계좌 변화
- 수익 기여 상위와 손실 기여 상위
- 매도 후 성과 회고
- 보유 기간별 성과 분석

### 4. 리스크와 노출 분석

- 종목 집중도
- 섹터 노출
- 원화/달러 노출
- 현금/주식/금/ETF 비중 변화
- 시장지수 및 환율과의 동행성

### 5. 예측과 이상징후

- 예측값 자체보다 실제값 이탈 여부에 초점
- 예측 범위를 벗어난 날의 원인 분석
- 모델별 성능 추적
- 계좌 급변, 특정 종목 과집중, 손실 확대 등 경고 지표 구축

### 6. 회고 리포트

- 주간/월간 포트폴리오 요약
- 주요 수익/손실 원인
- 매수/매도 이벤트 요약
- 리스크 변화 요약
- 다음에 확인할 항목 자동 정리

## 프로젝트 구조

```text
quant/
  app.py                         Flask 앱 진입점
  config.py                      환경변수 기반 설정
  extensions.py                  Flask 확장 객체
  data/
    csv_manager.py               CSV 스냅샷 정규화 및 파생 CSV 생성
    YYYY-MM-DD.csv               날짜별 원본 계좌 스냅샷
    account_value.csv            날짜별 총 계좌 평가금액
    portfolio_data.csv           최신 포트폴리오 정규화 파일
  db/
    connection.py                DB 연결
    migration.py                 CSV 데이터를 DB로 반영
  routes/                        Flask API 라우트
  services/                      포트폴리오, 스냅샷, 예측, 시장 분석 로직
  api/                           KIS, Finnhub API 연동
  static/js/                     대시보드 프론트엔드 로직
  templates/index.html           메인 화면
```

## 실행

```bash
pip install -r requirement.txt
python app.py
```

CSV를 재정규화하고 DB 마이그레이션까지 시도한 뒤 서버를 실행하려면 다음 옵션을 사용합니다.

```bash
python app.py --refresh
```

`--refresh`는 로컬 CSV와 DB 설정을 사용합니다. 실행 전 `.env`에 API 키와 DB 접속 정보가 준비되어 있어야 합니다.

## 환경변수

`.env`에는 API 키, 계좌번호, DB 비밀번호 같은 민감 정보가 들어갑니다. 이 파일은 저장소에 커밋하지 않습니다.

사용되는 주요 값은 다음과 같습니다.

- `FINNHUB_API_KEY`
- `appkey`
- `secretkey`
- `account`
- `id`
- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`
- `AUTO_REFRESH_CSV`
- `SNAPSHOT_DIR`

## 개발 메모

- 현재 프로젝트의 중심축은 “정확한 기록 -> 해석 -> 회고”입니다.
- 새 기능을 붙일 때는 먼저 이 기능이 투자 기록을 더 잘 이해하게 해주는지 확인합니다.
- 예측 모델 추가보다 데이터 품질, 이벤트 타임라인, 성과 원인 분석이 우선입니다.
- 외부 API 연동은 보조 정보로 두고, 개인 계좌 스냅샷을 가장 중요한 원천 데이터로 봅니다.
